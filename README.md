# 钱呱呱 3D 电路工作台

专门为使用 macOS、无法运行学校指定软件的大学生制作的浏览器 3D 电路工作台。

[在线打开 3D 工作台](https://qianfanting.github.io/qian-guagua-3d-circuit-workbench/) · [2D 工作台及源码](https://github.com/qianfanting/qian-guagua-circuit-workbench)

## 2D → 3D

在 [2D 工作台](https://qianfanting.github.io/qian-guagua-circuit-workbench/) 绘图后，点击“在 3D 工作台打开”，会在新标签页载入并转换为 3D 视图，同时下载一份 JSON 备份。也可以在 3D 工作台点击“打开工程”，选择从 2D 导出的 JSON 文件。

3D 工作台按 2D 工程中的元件位置、类型和导线连接建立立体视图。它是可旋转的展示及简化演示，不是物理精确仿真。部分特殊元件的 3D 外观可能使用通用模型。

## 本地使用

直接在浏览器打开 `index.html`。工程可保存为 JSON，日后重新导入。
